# Intelligent Vision Systems

Được. Với profile này mình sẽ không làm kiểu CV web khô cứng, mà theo hướng **portfolio cá nhân của AI / Computer Vision Engineer**, nhìn vào là thấy ngay chất `.NET + AI + Industrial Vision`.

Từ profile bạn gửi, phần giới thiệu hiện tại tập trung khá rõ vào **AI Engineer, Computer Vision, Industrial Defect Detection, C#/.NET/WPF**, cùng hướng kiến trúc Clean Architecture/CQRS. :chatgpt-content-reference{index="0"} Kinh nghiệm cũng có SotaVision và bài toán đưa Deep Learning vào hệ thống kiểm tra chất lượng thực tế. :chatgpt-content-reference{index="1"}

## Concept tổng thể

Tên trên web có thể dùng:

**NOLAN N. — AI ENGINEER**

Subtitle:

> **Building Intelligent Vision Systems for the Real World.**

Bên dưới:

> AI Engineer specializing in Computer Vision, Industrial AI, LLM Applications and high-performance .NET software.

Phong cách mình đề xuất là **Dark Tech / Minimal / Futuristic**, nhưng đừng quá cyberpunk. Nền gần đen, typography trắng/xám, điểm nhấn xanh electric hoặc tím nhẹ. Có grid mờ, glow, animation nhỏ và các card kiểu dashboard kỹ thuật.

Ảnh thuyết trình bạn gửi rất hợp làm **Hero background hoặc About section**; các ảnh đời thường còn lại nên làm gallery nhỏ ở cuối trang để web vẫn có cá tính nhưng phần đầu giữ hình ảnh chuyên nghiệp.
